# Contributing

Issues and pull requests are welcome.

1. Change code in `hooks/` or `scripts/`.
2. Add or update a test in `tests/`.
3. Run `npm test`.
4. Do not change the cost math in `scripts/cache-report.js` without a test that shows the new numbers.
5. For a release, bump the version in `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, and `package.json`, and add a line to `CHANGELOG.md`.

## Style

No em or en dashes, plain words, short sentences. State only what you ran.
